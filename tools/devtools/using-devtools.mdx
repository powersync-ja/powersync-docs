PowerSync DevTools has the same tabs in every host. This page describes each tab. To set up DevTools, read the [overview](/tools/devtools-overview).

## Header and Status Bar

<Frame caption="The DevTools header and status bar.">
  ![DevTools header with the Sync now and Clear and re-sync icon buttons, and the status bar below it](/images/tools/devtools-header.png)
</Frame>

The header and the status bar show on every tab.

The status bar shows the connection state, the sync activity, the number of buckets and downloaded operations, the number of local changes that wait to upload, and the last sync time. If an error occurs, the status bar shows it on the right.

The header has these controls:

| Control | Description |
|---|---|
| Database list | Selects the database to show. It shows only when more than one database is attached, for example when your app is open in two browser tabs. |
| **Sync now** | Requests a checkpoint and waits until the client is up to date. Your app must connect with `checkpointMode: 'requests'`. Read [Sync Catch-Up](/client-sdks/advanced/checkpoint-requests). |
| **Clear & re-sync** | Deletes the local data and downloads it again. Hold the button for one second to start it. |

## Sync Status

<Frame caption="The Sync Status tab.">
  ![Sync Status tab with connection details, download progress, and the upload queue](/images/tools/devtools-sync-status.png)
</Frame>

The **Sync Status** tab shows:

- The connection state, the endpoint, the connection method, and the user ID.
- The download progress, with progress for each priority.
- Download and upload errors.
- The upload queue: the local changes that wait to upload.

Use **Disconnect** and **Reconnect** to test how your app behaves offline and when it connects again.

## Data Inspector

<Frame caption="The Data Inspector tab with a SQL query.">
  ![Data Inspector tab with the table list and a SQL query result](/images/tools/devtools-data-inspector.png)
</Frame>

The **Data Inspector** tab lists your tables and views. Select one to see its rows.

It also has a SQL editor. Type a query and press `⌘+Enter` or `Ctrl+Enter` to run it. Queries run against the local SQLite database in your app. They do not go to your source database.

Your schema tables are views. The sync state of the client is in the internal `ps_*` tables, such as `ps_buckets`, `ps_oplog`, and `ps_crud`.

<Warning>
The SQL editor can also change data. A write to a view goes into the upload queue, like a write from your app.
</Warning>

## Buckets

<Frame caption="The Buckets tab.">
  ![Buckets tab with a list of buckets, their operations, and their size](/images/tools/devtools-buckets.png)
</Frame>

The **Buckets** tab lists the buckets on the client. For each bucket, it shows the downloaded operations and the size. Select a bucket to see its operations and rows.

To also see the total number of operations for each bucket, connect with `diagnostics: true`:

```typescript
await db.connect(connector, { diagnostics: true });
```

## Streams

<Frame caption="The Streams tab.">
  ![Streams tab with Sync Stream subscriptions and the subscribe form](/images/tools/devtools-streams.png)
</Frame>

The **Streams** tab lists your Sync Stream subscriptions. For each stream, it shows the parameters, the progress, the priority, and the time until the subscription expires.

Use the form to subscribe to a stream for a test. Enter the stream name and, if necessary, the parameters, TTL, and priority. By default, the TTL is 0, so the client removes the stream's data soon after you unsubscribe. Read [Sync Streams](/sync/streams/overview) for more about TTL and priority.

## Config

<Frame caption="The Config tab.">
  ![Config tab with connection details and the schema as JSON](/images/tools/devtools-config.png)
</Frame>

The **Config** tab shows:

- The connection details: the SDK, the endpoint, the user ID, the client ID, the connection method, the connection parameters, and the version of the PowerSync SQLite core.
- The schema, as a tree or as JSON.

The user ID comes from the `sub` claim of the JWT that your connector returns.

## Logs

<Frame caption="The Logs tab.">
  ![Logs tab with log records and the level filter](/images/tools/devtools-logs.png)
</Frame>

The **Logs** tab shows the log records of the PowerSync SDK. It starts to collect them when DevTools attaches to the database.

You can filter the records by level and search them. Use **Clear** to remove the records from the view.
