A Node.js app has no dev server with a browser dock. Your app process serves DevTools instead. You open the DevTools window in your browser.

## Requirements

- `@powersync/node`. {/* TODO: Add the minimum version after the release. It needs the `diagnostics` sync option and the `connector` accessor from `@powersync/common`. */}
- Node.js 20.16 or later.

## Set Up DevTools

<Steps>
  <Step title="Install the package">
    ```bash
    npm install -D @powersync/diagnostics
    ```
  </Step>
  <Step title="Enable DevTools in your app">
    Call `enablePowerSyncDiagnostics()` after you create the database. Call it in development only.

    ```typescript
    import { PowerSyncDatabase } from '@powersync/node';
    import { enablePowerSyncDiagnostics } from '@powersync/diagnostics/node';

    const db = new PowerSyncDatabase({ schema: AppSchema, database: { dbFilename: 'app.db' } });
    await db.connect(connector, { diagnostics: true });

    if (process.env.NODE_ENV !== 'production') {
      const devtools = await enablePowerSyncDiagnostics(db);
      console.log(`PowerSync DevTools: ${devtools.signInUrl}`);
    }
    ```

    `diagnostics: true` is optional. Without it, the **Buckets** tab does not show the total number of operations for each bucket.
  </Step>
  <Step title="Open the sign-in link">
    Start your app and open the link that it prints.

    The link contains a one-time code. The code is valid for five minutes and for one browser. After it expires, open `devtools.url`. The terminal then prints a new link.
  </Step>
</Steps>

To see what each tab shows, read [Using DevTools](/tools/devtools/using-devtools). The MCP endpoint is at `<url>/__mcp`. To connect a coding agent, read [MCP Tools](/tools/devtools/mcp).

## Options

Pass options as the second argument: `enablePowerSyncDiagnostics(db, { port: 4000 })`.

| Option | Default | Description |
|---|---|---|
| `port` | A random free port | The port of the DevTools window. A random port makes it harder for other websites to find the window. |
| `host` | `localhost` | The host that the server binds to. |
| `auth` | `true` | If `true`, the browser must sign in with a one-time code. If `false`, every local browser can open the window. |
| `open` | `false` | If `true`, the browser opens when the server starts. |
| `sdk` | `@powersync/node` | The SDK label that the UI shows. |
| `id` | `node-1` | The database ID that the UI and the MCP tools show. |
| `mcp` | `'auto'` | The MCP endpoint setting. See [MCP Tools](/tools/devtools/mcp#origin-and-authorization). |

<Warning>
If you set `host` to an address other than `localhost`, other devices on your network can reach DevTools. DevTools can read and change your local data. Keep `auth` set to `true` in that case.
</Warning>

## Return Value

`enablePowerSyncDiagnostics()` returns an object with these properties:

| Property | Description |
|---|---|
| `url` | The address of the DevTools window, such as `http://localhost:51234`. |
| `signInUrl` | The link to open. It contains the one-time code. If `auth` is `false`, it is the same as `url`. |
| `close()` | Stops the server and detaches the database. |
