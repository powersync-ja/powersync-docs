The queries and mutations above run against the local database. PowerSync uploads local writes and downloads server changes in the background, so local data can briefly lag behind the server.

To make sure local data is up to date at a specific moment, such as on pull-to-refresh or when a user opens a link to a record, create a [checkpoint request](/client-sdks/checkpoint-requests) and wait for it to sync. The wait also covers pending local writes: it completes after they have uploaded and their result has synced back. This alpha API requires PowerSync Service v1.24.0 or later and a [supported SDK version](/client-sdks/checkpoint-requests#prerequisites).
