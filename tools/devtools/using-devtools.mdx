PowerSync DevTools has the same tabs in Vite, Nuxt, and Node.js. To set it up, start with the [overview](/tools/devtools-overview).

## Header and Status Bar

<Frame caption="The DevTools header and status bar.">
  ![DevTools header with the Sync now and Clear and re-sync icon buttons, and the status bar below it](/images/tools/devtools-header.png)
</Frame>

The status bar stays visible on every tab and summarizes the sync state, including the latest error. The header has these controls:

| Control | Description |
|---|---|
| Database list | Selects the database to show. It appears only when more than one database is attached, for example when your app is open in two browser tabs. |
| **Sync now** | Requests a checkpoint and waits until the client is up to date. Your app must connect with `checkpointMode: 'requests'`. Read [Sync Catch-Up](/client-sdks/advanced/checkpoint-requests). |
| **Clear & re-sync** | Deletes the local data and downloads it again. Hold the button for one second to start it. |

## Sync Status

<Frame caption="The Sync Status tab.">
  ![Sync Status tab with connection details, download progress, and the upload queue](/images/tools/devtools-sync-status.png)
</Frame>

Use the **Sync Status** tab to check the connection, the download progress for each priority, and the local changes that are still waiting to upload. The tab also shows download and upload errors.

Use **Disconnect** and **Reconnect** to test how your app behaves offline and when it connects again.

## Data Inspector

<Frame caption="The Data Inspector tab with a SQL query.">
  ![Data Inspector tab with the table list and a SQL query result](/images/tools/devtools-data-inspector.png)
</Frame>

Use the **Data Inspector** tab to browse your tables and to run SQL against the local SQLite database in your app. To run a query, press `⌘+Enter` or `Ctrl+Enter`. Queries do not reach your source database.

The tables in your schema are SQLite views. The client's sync state is in internal `ps_*` tables, such as `ps_buckets`, `ps_oplog`, and `ps_crud`.

<Warning>
Writes in the SQL editor change your local data. A write to one of your schema tables goes into the upload queue, like a write from your app.
</Warning>

## Buckets

<Frame caption="The Buckets tab.">
  ![Buckets tab with a list of buckets, their operations, and their size](/images/tools/devtools-buckets.png)
</Frame>

The **Buckets** tab lists the buckets on the client, with the downloaded operations and size of each. Select a bucket to see its operations and rows.

To also see the total number of operations for each bucket, connect with `diagnostics: true`:

```typescript
await db.connect(connector, { diagnostics: true });
```

## Streams

<Frame caption="The Streams tab.">
  ![Streams tab with Sync Stream subscriptions and the subscribe form](/images/tools/devtools-streams.png)
</Frame>

The **Streams** tab lists your Sync Stream subscriptions, including when each one expires.

To test a stream, subscribe to it with the form. The form's TTL defaults to 0, so the client removes the stream's data soon after you unsubscribe. Read [Sync Streams](/sync/streams/overview) for more about TTL and priority.

## Config

<Frame caption="The Config tab.">
  ![Config tab with connection details and the schema as JSON](/images/tools/devtools-config.png)
</Frame>

The **Config** tab shows the connection details, such as the endpoint, user ID, and connection parameters, and your client schema.

The user ID comes from the `sub` claim of the JWT that your connector returns.

## Logs

<Frame caption="The Logs tab.">
  ![Logs tab with log records and the level filter](/images/tools/devtools-logs.png)
</Frame>

The **Logs** tab shows the PowerSync SDK's log records. It collects records only after DevTools attaches to the database, so earlier records do not appear.
