The best way to understand how PowerSync works is to explore it hands-on. Browse our collection of demo apps and example projects to see PowerSync in action, experiment with different features, or use as a reference for your own app.

All examples are organized by platform and backend technology. You can adapt any example to work with your preferred backend (see [App Backend](/configuration/app-backend)).

<Note>
  We continuously expand our collection of example projects. If you need an example that isn't available yet, [let us know on Discord](https://discord.gg/powersync).
</Note>

## Community

Browse the Community GitHub Org for community starter projects, templates, and demos:

<Card title="GitHub - powersync-community" icon="github" horizontal href="https://github.com/powersync-community">

The projects, tutorials, and articles below are from community members. We haven't necessarily vetted them, and some may use older PowerSync APIs or configuration. If you've built something with PowerSync or written about it, [open a pull request](https://github.com/powersync-ja/powersync-docs/edit/main/intro/examples.mdx) to add it to this list.

<AccordionGroup>
  <Accordion title="JavaScript & TypeScript" icon="js">
    - [How We Added E2E Encryption on Top of a Local-First Architecture](https://zentline.com/en/blog/end-to-end-encryption-on-top-of-local-first-sync/) by @doszhan
      - PowerSync syncs encrypted fields while local-only tables hold decrypted data.
    - [Why Your App Feels Slow and How We Fixed It with PowerSync](https://zentline.com/en/blog/why-your-app-is-slow-powersync/) by Zentline
      - A React and Django app uses PowerSync to move reads and writes to local SQLite.
    - [Hands-on with React, Supabase, and PowerSync](https://www.infoworld.com/article/4168581/developing-local-first-apps-with-react-supabase-and-powersync.html) by Matthew Tyson, InfoWorld
      - React and Supabase tutorial covering PowerSync setup and reactive SQLite queries.
    - [Account Optional Apps with PowerSync](https://www.maxmntl.com/blog/optional-account-powersync/)
      - Tutorial on letting users work locally without an account and enabling sync after they sign up.
    - [StackRender by @stackrender](https://github.com/stackrender/stackrender)
      - React schema editor that stores diagrams locally with PowerSync and the [Drizzle driver](/client-sdks/orms/js/drizzle).
    - [SolidJS Hooks for PowerSync Queries by @aboviq](https://github.com/aboviq/powersync-solid)
      - SolidJS hooks expose reactive PowerSync queries and connection status.
    - [Tauri + Shadcn UI by @MrLightful](https://github.com/MrLightful/powersync-tauri)
      - Tauri and React desktop template that uses PowerSync with native SQLite.
  </Accordion>

  <Accordion title="Dart & Flutter" icon="flutter">
    - [Flutter Instagram Clone by @itsezlife](https://github.com/itsezlife/flutter-instagram-offline-first-clone)
      - Flutter app that uses PowerSync to sync local app data with Supabase.
    - [Jepsen PowerSync Testing by @nurturenature](https://github.com/nurturenature/jepsen-powersync)
      - Jepsen tests check PowerSync consistency under network failures using Dart clients.
    - [Bavard by @ILDaviz](https://ildaviz.github.io/bavard/)
      - Dart and Flutter ORM with a documented PowerSync adapter.
  </Accordion>

  <Accordion title="Custom Backends" icon="screwdriver-wrench">
