Each example implements the two methods of a [backend connector](/configuration/app-backend/client-side-integration#backend-connector): `fetchCredentials()` and `uploadData()`. The Rust SDK splits these into an `Authenticator` and a `MutationUploader`. Copy the example for your SDK into your app, then replace the placeholders.

## Custom Backend

Use these examples if your app uploads writes to its own backend. By default, they call the [reference write API](/handling-writes/write-path/reference-write-implementation)'s `POST /api/data`. If your API's request or response format differs, either change the request and response handling in `uploadData()` to match your API, or use the [prompt for your coding agent](/handling-writes/write-path/existing-api#prompt-for-your-coding-agent) to generate an `uploadData()` for it.

Each example sends the same JWT to your PowerSync instance and to the write API. Replace the token placeholder with a token from your auth provider. See [Authentication Setup](/configuration/auth/overview).
