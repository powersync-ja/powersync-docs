Add the [PowerSync Web NPM package](https://www.npmjs.com/package/@powersync/web) to your project:

<Tabs>
  <Tab title="npm">
    ```bash
    npm install @powersync/web
    ```
  </Tab>

  <Tab title="yarn">
    ```bash
    yarn add @powersync/web
    ```
  </Tab>

  <Tab title="pnpm">
    ```bash
    pnpm install @powersync/web
    ```
  </Tab>
</Tabs>
