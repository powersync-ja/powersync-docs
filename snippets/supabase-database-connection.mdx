1. In your Supabase Dashboard, click **Connect** in the top navigation bar, or open [this link](https://supabase.com/dashboard/project/_?showConnect=true&connectTab=direct).
2. Select **Direct**, keep **Direct connection** as the connection method, and copy the connection string, including the `[YOUR-PASSWORD]` placeholder.
3. In the [PowerSync Dashboard](https://dashboard.powersync.com/), select your project and instance and go to the **Database Connection** view.
4. Select the **Postgres** tab.
5. Paste the connection string into the **URI** field. PowerSync fills in the other connection fields from the URI.
6. Change **Username** and **Password** to the `powersync_role` and password you created when you set up Supabase for PowerSync. See [Source Database Setup](/configuration/source-db/setup#supabase).
7. Keep **SSL Mode** set to `verify-full`. PowerSync trusts Supabase's certificate by default, so you don't need to add a server certificate.
8. Click **Test Connection** and fix any errors.
9. Click **Save Connection**.

PowerSync now creates an isolated cloud environment for your instance. This typically takes a minute or two.
