The authenticator implements `resolveCredentials()`, which returns the token. For development, return a [development token](/configuration/auth/development-tokens). When you get tokens from a backend, cache the token in your authenticator and clear the cache in `invalidateCredentials()`, which the SDK calls when it needs a new token. Don't rely on the SDK to cache the token, because it can call `resolveCredentials()` often, for example on every reconnect. See [When `resolveCredentials()` is Called](/configuration/app-backend/client-side-integration#when-resolvecredentials-is-called) for details.
