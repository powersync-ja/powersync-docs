Development tokens are temporary tokens that let your app connect to PowerSync before you integrate an auth provider. Each token signs in as the user ID you choose, so you can also use one to check what a specific user syncs.

## Generating a Development Token

<Tabs>
  <Tab title="PowerSync Cloud">
    1. In the [PowerSync Dashboard](https://dashboard.powersync.com/), select your project and instance
    2. Go to the **Client Auth** view
    3. Check the **Development tokens** setting and save your changes
    4. Click the **Connect** button in the top bar
    5. Enter a user ID:
       - If your data isn't filtered by user (same data syncs to all users), you can use any value (e.g., `test-user`).

    - If your data is filtered by <Tooltip tip="Values such as user ID that are used to determine which data syncs to which user.">parameters</Tooltip>, use a user ID that matches a user in your database. PowerSync uses this (e.g. `auth.user_id()` in Sync Streams) to determine what to sync.

    6. Click **Generate Token** and copy the token

    <Note>
      Development tokens expire after 12 hours.
    </Note>
  </Tab>
  <Tab title="Self-Hosted">
    Follow the steps below. Steps 1 and 2 configure signing keys and your PowerSync Service config; in Step 3 you can use the PowerSync CLI (recommended) or the [test-client](https://github.com/powersync-ja/powersync-service/tree/main/test-client) to generate the token.

## Usage

### Using with Your Application

While you build your app, use a development token to connect it to PowerSync. Return the token from `resolveCredentials()` in your [authenticator](/configuration/app-backend/client-side-integration#authenticator). The setup guide shows [the full connect call for each SDK](/intro/setup-guide#connect-to-powersync-service-instance).

<CodeGroup>

```typescript TypeScript
async resolveCredentials() {
  // For development: return your development token
  return 'your-development-token-here';
}
```

```rust Tauri (Rust)
// For Tauri, implement your authenticator in Rust
async fn resolve_credentials(&self) -> Result<Arc<String>, PowerSyncError> {
    // For development: return your development token
    Ok(Arc::new("your-development-token-here".to_string()))
}
```

### Using with Sync Test

If you're on PowerSync Cloud, use [Sync Test](/tools/sync-test#sync-test) in the PowerSync Dashboard to check what a specific user syncs. Sync Test generates a development token for the user ID you enter and connects a client in your browser with it. You do not need to copy the token.

### Using with the Sync Diagnostics Client

If you self-host, use the [Sync Diagnostics Client](https://diagnostics-app.powersync.com) to check what a specific user syncs. See [Test What a User Syncs](/tools/sync-test#sync-diagnostics-client) for the steps.

### Using with `test-client`

The [test-client](https://github.com/powersync-ja/powersync-service/tree/main/test-client) syncs without storing data in a client-side SQLite database. You can use it for load testing, for example to simulate many clients syncing at the same time. See the [README](https://github.com/powersync-ja/powersync-service/tree/main/test-client#readme) for how to pass the development token to its commands.
