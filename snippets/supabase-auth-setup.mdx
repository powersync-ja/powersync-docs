1. In the PowerSync Dashboard, go to the **Client Auth** view.
2. Select **Use Supabase Auth**.
3. If your Supabase project uses legacy JWT secrets, copy the JWT secret from your project's [JWT Keys](https://supabase.com/dashboard/project/_/settings/jwt) settings into **Supabase JWT Secret (optional)**. If your project uses JWT signing keys, leave this field empty. PowerSync configures your project's signing keys automatically.
4. Click **Save and Deploy**.
