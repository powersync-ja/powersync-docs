Each SDK tab has two files. The first is an [authenticator](/configuration/app-backend/client-side-integration#authenticator), which gives the SDK a token so it can download data, and a `connect()` call for downloads only. The second is a [mutation uploader](/configuration/app-backend/client-side-integration#mutation-uploader), which sends local writes to your backend, and a `connect()` call for downloads and uploads that replaces the first one. You can start with the authenticator and add the uploader when your app writes data.

Each authenticator caches its token and clears the cache in `invalidateCredentials()`, because the SDK isn't guaranteed to cache tokens. The Kotlin Supabase example is an exception: it uses the `SupabaseAuthenticator` and `SupabaseUploader` classes from the Kotlin SDK's Supabase integration, and `SupabaseAuthenticator` reads the token from the Supabase client's current session on each call.

Copy the files for your SDK into your app, then replace the placeholders.

## Custom Backend

The authenticator returns a placeholder token. Replace it with a token from your auth provider. See [Authentication Setup](/configuration/auth/overview).

The uploader calls the [reference write endpoint](/handling-writes/write-path/reference-write-implementation), `POST /api/data`, and sends it the authenticator's token. The write endpoint accepts the same JWTs as your PowerSync instance. If your API's request or response format differs, either change the uploader's request and response handling to match your API, or use the [prompt for your coding agent](/handling-writes/write-path/existing-api#prompt-for-your-coding-agent) to generate an uploader for it.

## Supabase

The authenticator signs users in with Supabase Auth and gives the SDK their access token. The uploader writes to Supabase with the Supabase client SDK, which is the [PostgREST route](/handling-writes/write-path/supabase-postgrest). There is no Supabase example for Rust.

To write through the [Supabase Edge Function](/handling-writes/write-path/supabase-edge-function) instead, use the Supabase authenticator with the reference write endpoint uploader from [Custom Backend](#custom-backend).
