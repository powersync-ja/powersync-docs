1. In the Neon Console, click **Connect**, turn off **Connection pooling**, and copy the connection string. Neon recommends a direct connection for logical replication. A direct connection string doesn't include `-pooler` in the hostname.
2. In the [PowerSync Dashboard](https://dashboard.powersync.com/), select your project and instance and go to the **Database Connection** view.
3. Select the **Postgres** tab.
4. Paste the connection string into the **URI** field. PowerSync fills in the other connection fields from the URI.
5. Change **Username** and **Password** to the `powersync_role` and password you created in [Create a PowerSync Database User](/integrations/neon#create-a-powersync-database-user).
6. Keep **SSL Mode** set to `verify-full`. PowerSync trusts Neon's certificate by default, so you don't need to add a server certificate.
7. Click **Test Connection** and fix any errors.
8. Click **Save Connection**.

PowerSync now creates an isolated cloud environment for your instance. This typically takes a minute or two.

### Configure Neon Auth

The demo app sends PowerSync the JWT that Neon Auth issues for the signed-in user. To verify these JWTs, PowerSync needs the public keys that Neon Auth publishes as a JSON Web Key Set (JWKS), and the audience (`aud`) value that Neon Auth puts in each token. You can find both URLs that you need in the Neon Console under **Settings** > **Better Auth**.

In the PowerSync Dashboard, go to the **Client Auth** view and set the following fields:

- **Development tokens:** Enable this setting. You use a development token to [test your Sync Streams](/integrations/neon#test-your-sync-streams-optional) at the end of this guide.
- **JWKS URI:** Enter the **JWKS URL** from Neon, for example:
  ```text
  https://ep-cool-darkness-123456.neonauth.c-2.us-east-2.aws.neon.tech/neondb/auth/.well-known/jwks.json
  ```
- **JWT Audience:** Enter the origin of the **Auth URL** from Neon. This is the URL without the path and without a trailing `/`, for example:
  ```text
  https://ep-cool-darkness-123456.neonauth.c-2.us-east-2.aws.neon.tech
  ```
  PowerSync rejects a token if its `aud` value doesn't match exactly.

Then click **Save and Deploy**.
