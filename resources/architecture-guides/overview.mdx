## By Industry

Many industries have use cases where apps need to continue working even if the network connection is unreliable or a device goes offline. Developers often end up with a "DIY" offline-first implementation that's a complicated mess, since bi-directional syncing becomes fraught with complexity and subtle edge cases the deeper down the complexity rabbithole you go. PowerSync handles that complexity for you, on the read path (change feeds, deltas, partial sync, tombstones, reactivity, etc.) and write path (outbox, retries, idempotency keys, conflict resolution, etc.), letting you focus on the business use case.
