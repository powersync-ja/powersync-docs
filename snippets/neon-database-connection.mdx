1. In the Neon Console, click **Connect**, turn off **Connection pooling**, and copy the connection string. Neon recommends a direct connection for logical replication. A direct connection string doesn't include `-pooler` in the hostname.
2. In the [PowerSync Dashboard](https://dashboard.powersync.com/), select your project and instance and go to the **Database Connection** view.
3. Select the **Postgres** tab.
4. Paste the connection string into the **URI** field. PowerSync fills in the other connection fields from the URI.
5. Change **Username** and **Password** to the `powersync_role` and password you created in [Create a PowerSync Database User](/integrations/neon#create-a-powersync-database-user).
6. Keep **SSL Mode** set to `verify-full`. PowerSync trusts Neon's certificate by default, so you don't need to add a server certificate.
7. Click **Test Connection** and fix any errors.
8. Click **Save Connection**.

PowerSync now creates an isolated cloud environment for your instance. This typically takes a minute or two.
